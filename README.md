# Система развития

Личное приложение саморазвития в стиле «Системы» из манхв: уровни, характеристики, ежедневные задания, штрафная зона, магазин наград и облачное сохранение.

Открыть: https://steakpick.github.io/sistema/
На iPhone: открыть ссылку в Safari → «Поделиться» → «На экран Домой».

## Устройство

Обычный сайт без сборки: GitHub Pages раздаёт файлы как есть.

| Файл | Что внутри |
| --- | --- |
| `index.html`, `styles.css` | разметка и оформление |
| `src/game.js` | правила игры: опыт, уровни, ежедневки, штрафы, награды, история дней, щит серии, подземелья, эффекты характеристик, достижения, недельный отчёт. Без DOM, покрыто тестами |
| `src/main.js` | интерфейс: отрисовка, формы, вкладки, уведомления, заставка |
| `src/setup.js` | первый запуск: имя, наборы целей, режим, награды; добавление наборов из настроек |
| `src/progress.js` | календарь, графики целей, неделя, достижения, подземелья, щит: готовая разметка для экранов |
| `src/sync.js` | аккаунт (почта и пароль) и облачное сохранение в Supabase |
| `src/store.js` | сохранение на телефоне |
| `src/i18n.js`, `src/en.js` | русский и английский интерфейс |
| `src/fx.js`, `src/sound.js` | анимации, звуки, отклик |
| `src/boot.js`, `src/native.js` | запуск; в iOS-приложении: сохранение в память iPhone, вибро-отклик, экран не гаснет на таймере |
| `fonts/` | шрифты внутри приложения, без загрузки из интернета |
| `sw.js`, `manifest.webmanifest` | работа без интернета и установка на экран «Домой» |
| `ios/`, `capacitor.config.json` | iOS-приложение (Capacitor) |

## Проверка

```
npm test
```

Тесты идут на Node 20+ и проверяют логику дней (пропуски, штрафы, переход на летнее время), наборы целей первого запуска, щит, подземелья, эффекты, достижения, недельный отчёт и выбор, какое сохранение оставить при синхронизации.

## Облако

Supabase, таблица `public.saves` (одна строка на игрока, доступ только к своей строке через RLS). В приложении лежит только publishable-ключ.

## iOS-приложение

То же приложение, упакованное в настоящее iOS-приложение через Capacitor. Всё работает без интернета, сохранение лежит на самом iPhone (дважды: в хранилище веб-движка и в памяти приложения iOS, чтобы iOS не могла его стереть при очистке кэша). Облако остаётся по желанию в настройках.

Что нужно один раз: Mac с Xcode (App Store) и Node.js 20+ (nodejs.org).

```
npm install
npm run ios:sync   # копирует сайт в www/ и в Xcode-проект
npm run ios:open   # открывает проект в Xcode
```

В Xcode: проект App → вкладка Signing & Capabilities → Team: свой Apple ID (Add Account…). Подключить iPhone кабелем, выбрать его сверху и нажать ▶.
На iPhone один раз: Настройки → Конфиденциальность и безопасность → Режим разработчика → вкл.; Настройки → Основные → VPN и управление устройством → доверять своему Apple ID.

С бесплатным Apple ID приложение работает 7 дней, потом его надо снова запустить из Xcode (данные сохраняются). С платным аккаунтом разработчика (99 $ в год) можно ставить через TestFlight на год.

После любых правок сайта: `npm run ios:sync` и снова ▶ в Xcode.
