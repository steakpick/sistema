# Система развития

Личное приложение саморазвития в стиле «Системы» из манхв: уровни, характеристики, ежедневные задания, штрафная зона, магазин наград и облачное сохранение.

Открыть: https://steakpick.github.io/sistema/
На iPhone: открыть ссылку в Safari → «Поделиться» → «На экран Домой».

## Устройство

Обычный сайт без сборки: GitHub Pages раздаёт файлы как есть.

| Файл | Что внутри |
| --- | --- |
| `index.html`, `styles.css` | разметка и оформление |
| `src/game.js` | правила игры: опыт, уровни, ежедневки, штрафы, награды. Без DOM, покрыто тестами |
| `src/main.js` | интерфейс: отрисовка, формы, вкладки, уведомления, заставка |
| `src/sync.js` | аккаунт (почта и пароль) и облачное сохранение в Supabase |
| `src/store.js` | сохранение на телефоне |
| `src/i18n.js`, `src/en.js` | русский и английский интерфейс |
| `src/fx.js`, `src/sound.js` | анимации, звуки, отклик |
| `sw.js`, `manifest.webmanifest` | работа без интернета и установка на экран «Домой» |

## Проверка

```
npm test
```

Тесты идут на Node 20+ и проверяют логику дней (пропуски, штрафы, переход на летнее время) и выбор, какое сохранение оставить при синхронизации.

## Облако

Supabase, таблица `public.saves` (одна строка на игрока, доступ только к своей строке через RLS). В приложении лежит только publishable-ключ.
